# Custom Drive Bias / Symmetry

## 컨트롤

- **Bias 0–100%**는 Stage B의 기존 동적 동작점에 정규화 오프셋 −0.30~+0.30을 더한다. 값을 올리면 양의 입력이 먼저 클리핑 영역에 들어가고 음의 입력 쪽에는 여유가 생긴다. 50%는 기존 동작점이다. 무입력 성분은 기존 방식대로 클리핑 함수에서 빼고, Wet 출력에는 기존 12 Hz DC 차단이 적용된다.
- **Symmetry 0–100%**는 Stage B의 양·음 반주기에서 클리핑 무릎과 출력 레일을 함께 배율 조정한다. 0%에서 양·음 배율은 0.76 / 1.24, 100%에서 1.24 / 0.76이다. 50%에서 두 배율은 1.0이고 기존 Bias와 텍스처가 유지된다. 최종 파형의 극성별 피크에는 Stage A와의 혼합 및 DC 차단도 반영된다.
- 기존 프리셋과 AU 상태에 새 항목이 없으면 둘 다 50%로 열린다. 실시간 변경에는 엔진의 기존 20 ms 시정수 스무딩을 사용한다. Headroom 및 Mid Character는 청취 중 현재 세션 값을 고정한다.

## 오프라인 DSP 측정

48 kHz, 2×, 440 Hz 사인, Drive 50, Headroom 50, Level −6 dB, 나머지 기본값이다. 이전 Logic 관측값에 맞춰 입력 peak를 −7.2 dBFS로 설정했다. 짝수 합은 H2–H12, 홀수 합은 H3–H11의 제곱합 제곱근이며 모두 기본음 기준 dBc다.

| Bias / Symmetry | 양 / 음 출력 peak | Peak / RMS dBFS | H2 / H3 dBc | 짝수 / 홀수 합 dBc | THD |
|---|---:|---:|---:|---:|---:|
| 50 / 50 | +0.323 / −0.337 | −9.44 / −11.51 | −29.6 / −16.8 | −27.9 / −16.3 | 15.80% |
| 0 / 50 | +0.338 / −0.330 | −9.43 / −11.38 | −35.4 / −16.5 | −32.9 / −15.9 | 16.12% |
| 100 / 50 | +0.308 / −0.344 | −9.26 / −11.69 | −21.6 / −18.0 | −20.1 / −17.8 | 16.32% |
| 50 / 0 | +0.318 / −0.354 | −9.02 / −11.40 | −22.3 / −17.6 | −21.1 / −17.2 | 16.37% |
| 50 / 100 | +0.325 / −0.320 | −9.76 / −11.70 | −40.1 / −16.5 | −39.6 / −16.0 | 15.90% |

- **클리핑과 레벨.** Drive 75, 50/50에서 입력을 −7.2에서 0 dBFS로 올렸을 때 출력 양·음 peak는 +0.323 / −0.329에서 +0.338 / −0.341로 변해 두 반주기의 포화를 확인했다. Drive 50, −7.2 dBFS에서 9개 조합의 출력 peak는 −10.04~−8.55 dBFS, RMS는 −12.15~−11.29 dBFS였다. −24 dBFS 입력에서는 RMS가 −22.30~−20.76 dBFS였다. Drive 75, Bias 100, Symmetry 0에서 Level을 −12 / −6 / 0 dB로 높이면 출력 RMS도 단계마다 6 dB씩 올랐다.
- **DC와 기존 출력.** 69개 정상상태 측정의 출력 평균 절댓값은 최대 7.9×10⁻¹⁰이었다. Bias/Symmetry 50/50에서 Headroom 0/50/100 × 오버샘플링 1×/2×/4× 전 조합의 비교 파형이 기존 샘플과 정확히 일치했다.
- **자동화.** 400 Hz 기준 신호에서 50→100 변경 시 고정 컨트롤과의 차분 파형에 대해 인접 샘플 변화량을 측정했다. 2×에서 Bias 0.00120, Symmetry 0.00111이 관측됐다. 엔진의 스무딩을 끈 대조 빌드에서는 0.003 제한을 확인하는 테스트가 실패했다.
- **CPU.** 이 Mac의 Release 스테레오 DSP, 48 kHz / 128프레임, 기본값·극단값·자동화 각각 9쌍 교차 측정의 중간값 기준이다. 기존 대비 1× +7.4~8.7% (13.2~13.5 μs), 2× +0.4~1.7% (77.2~77.7 μs), 4× +0.1~2.2% (138.3~138.7 μs)였다. 한 블록 처리 시간은 2.67 ms 주기의 약 0.5%, 2.9%, 5.2%다. Logic 세션의 처리 부하는 청취 중 Logic의 성능 미터에서 확인한다.

## Logic Pro AU 청취 절차

1. Logic을 닫고 기존 AU를 보관한 뒤 후보 `Multi Effects.component`를 사용자 `~/Library/Audio/Plug-Ins/Components`에 설치한다. Logic을 다시 열고 플러그인 상단의 `BiasSymmetry-v1`과 Custom Drive의 새 컨트롤 두 개를 확인한다. `프로젝트.logicx`의 작업용 사본에서 Track 2 `오디오 1`의 `test_copy_1` DI와 기존 Multi Effects 인서트를 사용한다. 사이클을 **24.1.1.1부터 27.1.1.1 직전까지** 설정한다.
2. Input Trim 0 dB와 기존 Gate·Compressor·Gain 우회를 확인한다. Headroom, Mid Character, Tone, Crunch, Grain, Tight, Level, 오버샘플링 및 이후 체인을 고정하고 Mix는 100%로 설정한다. 이전 −7.2 dBFS는 20 ms 창에서 관측한 최대 입력 peak다. 이번 재생에서도 실제 입력 peak를 기록한다.
3. Drive 50, Bias/Symmetry 50/50을 기준으로 **0/50 → 50/50 → 100/50**, 이어서 **50/0 → 50/50 → 50/100**을 렌더한다. 동일한 프리롤에서 시작해 같은 세 마디를 비교한다. 필요하면 Drive 25와 75, 또는 두 컨트롤의 교차 극단을 같은 방식으로 확인한다.
4. 첫 비교는 Level 고정과 바운스 정규화 해제 상태에서 한다. 각 설정의 전체 구간 peak/RMS와 Clip 표시를 기록한다. 두 번째 비교는 AU 뒤의 Logic Gain으로 같은 구간 RMS를 ±0.2 dB 안으로 맞춰 순서를 바꿔 듣는다. 피킹 어택, 화음의 거칠기, 감쇠 꼬리를 기준으로 선호 설정과 해당 마디·박을 기록한다.
5. 지속음과 감쇠 끝에서 Bias와 Symmetry의 0↔100 변경을 각각 자동화한다. 사이클 경계에서 떨어진 지점에 전환을 배치한다. 고정값 재생과 비교하며 클릭·팝, 새 피크, 드롭아웃, Logic 성능 미터를 확인한다.

기록 항목은 Drive/Bias/Symmetry, 고정한 Headroom/오버샘플링, 입력 peak, 출력 peak/RMS, 후단 매칭 게인, 청감 메모와 승인 여부다. Bias/Symmetry와 기존 Headroom의 청감 승인 여부를 각각 기록한다.
