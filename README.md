# Multi-Effects DSP Project

기타용 소프트웨어 멀티이펙터를 직접 구현하는 개인 프로젝트입니다.

## Goal

- Guitar DSP 기본 원리 학습
- Block 기반 멀티이펙터 구조 구현
- Amp / Cab / Delay / Reverb 등 구현
- NAM 기반 Amp Capture 모델 연동
- VST3 플러그인 개발
- 최종적으로 Embedded Hardware로 이식
